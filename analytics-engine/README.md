# CrediMerge Financial Analytics Engine

## Purpose

This is Member 3's independent financial analytics engine for CrediMerge.

## Responsibilities

- Financial calculations
- Loan analytics
- Consolidation analytics
- Risk simulation
- Transaction analytics
- Alternative Credit Health analytics

## Architecture

```text
React Frontend
    ↓
Node/Express Backend
    ↓
Python Financial Analytics Engine
    ↓
Result
    ↓
Backend
    ↓
Frontend
```

## Important architecture rules

1. Frontend must not contain financial calculation logic.
2. Node/Express backend must act mainly as API/database/orchestration layer.
3. Python analytics-engine owns financial calculations and analytical logic.
4. Gemini is not the calculation engine.
5. Credit Health calculations must be generated by this analytics engine.
6. The engine must remain independently testable.

This foundation intentionally contains no financial calculations, Credit Health logic, or APIs yet.
